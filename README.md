To install the add-on in Blender version 5.0.1, go to Preferences -> Add-ons, install from disk.
Then press the "N" key to open the side panel, and you will see "3DO + Key" there. Import your 3DO model.
The corresponding animations of the model will automatically appear; if they do not, there is an option to add the (Optional) folder where the animations are located, which will also automatically appear in the list.
Otherwise, search manually using the import animations button. Importing animation is also available in the File -> Import... menu.
The purpose of this Add-on is only to load .3do models and .key animations. 
Textures and materials are not necessary because they are only added manually. 
And how do you know which textures belong to the object? :)
